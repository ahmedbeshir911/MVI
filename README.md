# MVI — Social Media Design Studio

A premium Arabic landing page for monthly social media design packages.

## Packages
- 1 post / day — Starter
- 2 posts / day — Growth
- 3 posts / day — Business
- 5 posts / day — Premium

## Stack
Vanilla HTML, CSS and JavaScript. No build step required.

## Customize
Update the WhatsApp link in `script.js`, package details/pricing in `index.html`, and visual identity in `styles.css`.
